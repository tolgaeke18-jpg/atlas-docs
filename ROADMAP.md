# Atlas Product Roadmap

**Version:** 0.1.0

**Status:** Active

**Owner:** Atlas Labs

---

# Vision

Build the world's most intelligent EV companion by transforming complex vehicle, charging, and journey data into simple, actionable decisions.

Atlas is not just another EV application.

Atlas is an EV Intelligence Platform.

---

# Product Strategy

Atlas will be developed in multiple phases.

Each phase delivers a usable product while building the foundation for future capabilities.

---

# Phase 1 — Foundation (Sprint 1)

**Target Duration:** 2 Weeks

## Goals

- Establish project architecture
- Build development environment
- Prepare backend
- Create documentation
- Design database
- Create API contracts

### Deliverables

- Flutter project
- Supabase project
- Documentation
- Authentication
- Vehicle Library
- Database
- CI/CD Pipeline

**Status:** In Progress

---

# Phase 2 — MVP

**Target Duration:** 30 Days

## Goals

Deliver the first usable version of Atlas.

### Features

- User Authentication
- Garage
- Home Dashboard
- Vehicle Library
- Trip Planner
- Charging Planner
- Favorite Stations
- User Profile

### Success Criteria

Users can:

- Register
- Add a vehicle
- Plan a trip
- Receive charging recommendations

**Status:** Planned

---
